# 主要特性与交付状态

测试场为通用 coding AI 提供公开一致的游戏角色、工具、资料与有限资源。AI 自主选择策略和执行方式，比赛结果用于比较效果。

开始操作可先读 [玩家入门](PLAYER.md)。下列“已实现”指源码已有对应能力；本地验证与实战验收范围见 [验证记录](VALIDATION.md)。部署配置由运营者完成，“可自组织”由参赛代码安排。

## 比赛与角色

1. **PvP 竞速比赛｜已实现，需配置地图。** 围绕 Race of Wool 一类目标组织准备、开局、比赛和结束。运营者固定地图、队伍、时限与获胜规则。实战适配器按纪念碑当前方块状态计分，选图须与此判定方式一致。[比赛宿主](../packages/arena/README.md)

2. **每个参赛单位一个容器、一个角色｜部署模板已提供。** Pi 和参赛代码在容器内运行，真实 Mineflayer bot 在可信后端运行。模板给出网络、CPU、内存与进程限制；目标 Docker 主机上的隔离效果须验收。[运营部署](../infra/README.md)

3. **自由编程与执行方式｜已实现。** AI 可逐步操作，也可写普通 Node 函数、脚本、事件监听器和 Promise，自主组织采集、施工、战斗与角色控制。[参赛指南](../examples/SKILL.md)

## 观察与游戏执行

4. **Mineflayer 风格状态与动作、选定插件｜已实现，兼容范围有界。** 同步本地镜像支持查询与寻路；公开语义动作由可信后端校验执行。提供固定版本 Pathfinder/PvP 适配、自定义 Goal 与 Movements；动态地形和实战行为须按选图验证。[SDK 与兼容清单](../packages/bot-sdk/README.md)

5. **俯视与三维观察｜已实现，材质截图待部署验收。** 图像工具同次返回裸图和坐标、覆盖、时间等元数据。CPU 俯视图／结构图已有验证；Prismarine 材质视图需要 Chromium，实际 WebGL 截图须在可运行环境验证。[视觉工具](../packages/world-visual/README.md)

6. **持续运行的普通程序｜已实现。** 程序可在模型思考、排队或暂时结束回答后继续运行。工具等待和进程寿命分开；AI 通过 taskId 等待结果或明确取消，比赛结束时运行时清理进程。[Pi 运行集成](../packages/pi-extension/README.md)

## 模型判断与资源

7. **程序主动报告与状态合并｜已实现。** 程序决定追加事件、按 key 替换状态或请求提前判断；Pi 扩展把消息附到模型可见边界。紧急投递释放受管工具等待并保留进程，常驻模式也可继续空闲中的同一会话。[收件箱](../packages/inbox/README.md)

8. **程序化组合工具结果｜已接入 Pi codemode。** AI 可用 JavaScript 调用工具、筛选普通输出和组合结果，按需转交原生图像块；独立投递的收件箱消息在外层结果交付。[用法示例](../examples/SKILL.md#codemode-preserve-only-useful-ordinary-output)

9. **按 API 标价折算成本的窗口限速与反馈｜已实现，需配置模型价格与速率。** 网关统一计量个人／队伍的参考成本，覆盖主 agent、子代理和摘要请求，按时间窗口容量排队。模型看到窗口内各计费项成本占比、速率超支比例、实际排队延迟和计量质量；运营者查看累计金额并通过可信 host 决定何时结束比赛。账本当前为单进程内存状态。[预算网关](../packages/budget-gateway/README.md)

## 协作、引导与结果

10. **队内 Git、游戏聊天与子代理｜部署接线与参赛自组织。** Git 共享卷已接入模板，运营者初始化队内仓库；聊天经游戏桥发送，其可见范围由服务器／地图配置。子代理可由参赛代码自行启动和调度，使用本参赛单位的网关身份与预算；平台提供运行和计量条件，调度与并发角色协调由参赛代码实现。[部署说明](../infra/README.md)

11. **一次开局任务与持续比赛上下文｜已实现。** 常驻 Pi 等待可信开局状态，提交一次公开任务说明。后续工具结果、程序报告、预算与墙钟反馈进入同一会话，终局状态触发清理。[启动与生命周期](../packages/pi-extension/README.md)

12. **短说明与可运行教学材料｜已提供。** 启动入口加载行为指南、编程技能和示例，涵盖动作、插件、视觉、报告和等待。AI 可据此修改程序并选择自己的策略。[短说明](../AGENTS.md) · [编程指南](../examples/SKILL.md)

13. **可信判定与结果记录｜已实现，实战对局待验收。** 比赛宿主接收可信目标信息，处理当前进度、超时和异常，保存结果与版本标识。真实地图重置、同步开局、目标观察和终止清理须完成实战冒烟验收。[比赛宿主](../packages/arena/README.md) · [验证记录](VALIDATION.md)
