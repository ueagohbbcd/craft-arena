## 模型调用与计量

容器内的 Pi 也可以自己登录模型服务（OAuth），这时平台无法再通过转发请求来计量。方向是：Pi 扩展在每次请求前向账本申请额度、请求后上报实际用量，再由出网代理统计流量做事后核对。

| 状态 | 事项                                                                                   |
| ---- | -------------------------------------------------------------------------------------- |
| ⬜   | 出网代理：只放行白名单域名，禁止访问宿主机和内网地址，按容器统计连接与流量             |
| ⬜   | 账本服务：从预算网关抽出价格表、窗口限速和比例反馈，提供"申请额度"和"上报用量"两个接口 |
| ⬜   | Pi 扩展在 `before_provider_request` 申请额度、请求结束后上报用量                       |
| ⬜   | 错误恢复改用 Pi 自带重试（调大次数），只保留重试耗尽后的兜底和输出截断后的续写         |
| ⬜   | 赛后核对：厂商后台用量、代理流量和上报用量三方对比                                     |
