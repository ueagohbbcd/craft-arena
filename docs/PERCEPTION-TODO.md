# 默认态势感知：工作清单

更新：2026-10-13。记录本轮工具箱接线整理、既有功能与后续候选。

## 架构归属

态势感知、世界视觉、共享区块记忆是并列的**预装工具箱**；Skill／示例负责说明调用、复用、改写。默认运行是产品选择，不意味着观察和渲染算法属于 Pi。后台任务、Inbox、角色授权与比赛制度才是框架功能。当前 Pi 会话托管默认观察连接；Bridge 默认初始化原生区块记忆；世界视觉已可由普通脚本调用。解耦时保持原有行为、数据新鲜度及比赛身份权限。

## 工具箱接线整理（2026-10-13）

本轮围绕玩家能实际修改预装能力整理，不另建工具箱管理框架。

- [x] 默认观察逻辑独立为 `packages/observation/default-observer.mjs`。
- [x] 观察器与聊天监听改为开局启动的普通脚本（`packages/default-scripts/`），作为受管后台任务运行，可停、可换；收件箱新增跨进程送达回执，替代同进程交付水位。Pi 扩展只保留默认脚本启动、运行时状态（`runtime.current`）与平台消息（时钟、预算）。此前 `perception.mjs` + `observe({reload:true})` 的替换机制随之删除。`perception.json` 仍可调整采样，观察器启动时读取。用法见[修改默认观察器](OBSERVATION.md#修改默认观察器)。
- [x] 区块记忆继续在可信 Bridge 收集原始数据；宿主可传入工厂或禁用。身份范围、卸载历史与当前／历史／未知状态保留，见[记忆接线](BLOCK-MEMORY.md#trusted-ownership-isolation-and-lifecycle)。
- [x] 开局渲染保留，失败提示改为按需脚本；修正代表坐标说明、已删除接口残留与 Skill 的双任务示例。

替换观察器用于改变行为；额外监听器用于并行处理具体任务。两者不混成一套新调度系统。视觉与记忆已有库及普通脚本足够使用，暂不增加统一注册、独立服务或自动文件重载。

本轮验证：Bridge 聚焦检查 30/30；观察与记忆相关批次 91 项中 90 通过，剩余一项受 Windows 原生 `/bin/bash` 子进程输出影响。新增替换回归与真实 Pi 观察／历史交付通过，语法检查通过。

后续遇到具体比赛中的漏失、迟到或噪声，再针对该决策比较观察覆盖和报告方式；本轮没有运行新的付费对局，也不据接口测试宣称比赛效果提升。下方保留既有功能记录与后续候选，未勾选项不代表本轮必须继续扩展的范围。

## 默认交付

默认采用普通 ReAct。开局提供 baseline，后续顶层工具返回附带发生变化的状态部分；每个出现的部分替换同部分旧值，空数组和 null 同样有效。查询、图片、事件和区间摘要进入历史。时间流逝本身不重复生成状态报告。

当前上下文设计包括主动执行的预期返回、后台收集后按需读取、普通 Inbox 合并和 early 判断。默认采集与默认交付分别选择；价值、成本与漏失责任见[项目设计说明](CONTEXT-DELIVERY.md)。早期临时尾部已移至该文的历史实验记录。

## 已实现

- [x] 近距方块扫描：从头部整格在半径内沿透明空间连通，包含相邻不透明边界；每秒采样，同报告内按方块位置去重，保留全部非空气类型。
- [x] 区间报告：时间段、实际已采样范围 3D bbox、唯一不透明边界面面积、每类方块数。跨报告不额外去重。
- [x] 收件箱延迟：生产者持续覆盖同 key 完整摘要，收件箱从首次 pending 创建起计算最小交付延迟，默认 30 秒；覆盖保持原到期时间，到期后在自然交付边界送达。
- [x] 消费回调：实际交付后按样本水位退休累计数据，保留较新样本。默认状态基线也在实际交付后推进，丢弃条目仍可补交。
- [x] 附近告示牌：近距样本展开正反面文字和未知面，以普通 Inbox 可替换状态报告。未交付文字保留到 onDelivered 确认；过期／挤出后重投，同集合往返合并，走开后的空集合保留先前待交付文字。完整查询保留精确位置与原始数据。
- [x] 实体雷达：可调距离、眼睛到实体中心的可见性筛选；非潜行玩家在较大范围显示坐标，保留可信队伍关系与状态。默认生物 48 格、玩家 64 格，可由 perception.json 调整。
- [x] 掉落物群：种子半径聚类，展示中心、物品分类数量、合计和实体数，未知堆叠数明确保留。
- [x] 普通历史去重：跳过未变部分，区间方块及告示牌交由各自生产者报告；旧远距告示牌列表从默认简要状态移除，按需查询仍可读取。
- [x] 区块方块记忆：保存角色实际收到的原生区块，加载期间同步变化、卸载保留、重载替换；区分维度和世界身份。
- [x] 独立只读访问：HTTP 异步查询区块／方块，显式 prefetch 后支持同步 MF 风格查询子集；无需控制角色或新增游戏登录。保留原生告示牌 NBT 和光照数据。
- [x] 近视回放客户端源码与构建：同仓库 tools/replay-myopia，绑定玩家、距离调节和开关独立于比赛部署；已构建并进入图形客户端。
