# 默认态势感知：工作清单

更新：2026-10-11。此页区分已实现、已有验证与待实战验收。

## 默认交付

默认采用普通 ReAct。开局提供 baseline，后续顶层工具返回附带发生变化的状态部分；每个出现的部分替换同部分旧值，空数组和 null 同样有效。查询、图片、事件和区间摘要进入历史。时间流逝本身不重复生成状态报告。

临时请求尾部状态栏保留为实验选项，`ARENA_PERCEPTION_TAIL=1` 开启，**默认关闭，尚未完成**。理论上，把变化内容放在稳定历史之后，能保留公共前缀的缓存收益，适用于大部分采用前缀缓存的供应商。具体断点、写入范围和 OAuth 端点效果仍待验证。旧临时观察从后续请求消失可能使模型困惑，模型适应性也尚未实测。

- [x] 近距方块扫描：从头部整格在半径内沿透明空间连通，包含相邻不透明边界；每秒采样，同报告内按方块位置去重，保留全部非空气类型。
- [x] 区间报告：时间段、实际已采样范围 3D bbox、唯一不透明边界面面积、每类方块数。跨报告不额外去重。
- [x] 收件箱延迟：生产者持续覆盖同 key 完整摘要，收件箱从首次 pending 创建起计算最小交付延迟，默认 30 秒；覆盖保持原到期时间，到期后在自然交付边界送达。
- [x] 消费回调：实际交付后按样本水位退休累计数据，保留较新样本。默认状态基线也在实际交付后推进，丢弃条目仍可补交。
- [x] 附近告示牌：近距样本中展开正反面文字和未知面，当前集合或文字变化通过普通事件交付。完整查询保留精确位置与原始数据。
- [x] 实体雷达：可调距离、眼睛到实体中心的可见性筛选；非潜行玩家在较大范围显示坐标，保留可信队伍关系与状态。默认生物 48 格、玩家 64 格，可由 perception.json 调整。
- [x] 掉落物群：种子半径聚类，展示中心、物品分类数量、合计和实体数，未知堆叠数明确保留。
- [x] 普通历史去重：跳过未变部分，区间方块及告示牌交由各自生产者报告；旧远距告示牌列表从默认简要状态移除，按需查询仍可读取。
- [x] 区块方块记忆：保存角色实际收到的原生区块，加载期间同步变化、卸载保留、重载替换；区分维度和世界身份。
- [x] 独立只读访问：HTTP 异步查询区块／方块，显式 prefetch 后支持同步 MF 风格查询子集；无需控制角色或新增游戏登录。保留原生告示牌 NBT 和光照数据。
