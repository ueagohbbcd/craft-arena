# 默认态势感知：工作清单

更新：2026-10-11。此页记录当前决策、实现和验收状态，便于接续工作。

## 默认交付

默认采用普通 ReAct：按需查询和图片作为工具结果进入历史；监控结果合并进入收件箱，在原本的工具返回等边界一起交付。区间摘要保留在历史中。状态未变时可省略重复报告，变化时提供可理解的更新。

临时请求尾部状态栏保留为实验选项，**默认关闭，尚未完成**。理论上，把变化内容放在稳定历史之后，能保留公共历史前缀的缓存收益，适用于大部分采用前缀缓存的供应商。具体缓存断点、写入范围和 OAuth 端点效果仍需验证，不能保证所有历史 token 每轮命中。

上一轮临时观察从后续请求消失，可能使模型困惑；这与缓存计费是两个问题，目前没有完成模型适应性实测。客户端保留历史 reasoning 数据也不能单独证明服务端实际使用。默认路径因此保留标准 ReAct 历史。

## 回放工具定位

近视滤镜帮助人观察默认感知范围的局限。真实模型得到的类型计数比带空间位置的回放画面更粗。回放可提供参考，但不能作为模型看到了相同图像的证据。客户端源码与构建独立，普通比赛可完全不播放回放。
