# 测试判据与重复实现审查（2026-10-18）

本轮以 `e26cb73` 为基线，集中检查模型配置、RPC 恢复、SDK 兼容测试及其实现。不是全仓每个测试的逐项认证；下列判断均有具体代码依据。

## 已修正的判据

| 原测试/实现 | 为什么不足 | 修正 |
| --- | --- | --- |
| `pi-extension.test.mjs` 接受输出上限 4096、压缩预留 2000 | 只验证配置原样写入，没有验证预算关系；可能在需要下一次完整输出之前耗尽可用上下文 | 启动器拒绝输出不小于上下文、预留不足和压缩后无剩余空间等配置；错误发生在写出可运行 profile 之前 |
| `windows-model-limits.test.mjs` 主要比对写入对象，通用描述符只检查 `generated` | 不能发现 Pi 加载配置时忽略字段、回退默认值或拒绝模型 | 通过安装的 Pi `ModelRuntime` 和 `SettingsManager` 读取文件，确认模型真实加载、没有加载错误，容量和压缩预算符合描述符 |
| `sdk-fidelity.test.mjs` 只比较方法名 | 一个同名空实现也可以通过；不能据此断言 Mineflayer 语义兼容 | 保留为明确标注的 API 清单冒烟测试；增加 Vector 行为测试 |
| 自写 Vector 的 `normalize()` 返回新对象 | 与原生 `vec3` 原地修改的契约不一致，方法名测试发现不了 | 使用已有 `vec3`，仅保留零参数构造默认值；验证原地修改、返回身份、`unit()` 的复制行为及零向量 |
| RPC 输出解析将消费者抛错与日志噪声同样吞掉 | 输入是有效事件时，消费失败是程序错误；静默继续可能使恢复逻辑失效 | 单独报告消费者错误，启动器记录原因并以失败状态关闭；普通非 JSON 日志仍可忽略 |
| 桥动作测试深比较 position 与 clone 的对象类型 | “停止不移动”的要求与向量子类原型是否相同无关；复用原生 vec3 后出现假回归 | 比较三维坐标，保留实际位置约束 |

没有删除原有错误处理、隔离、动作与重连测试。名称为“recovers requests or reports terminal runtime failure”的 RPC 集成测试看起来宽松，但实际针对 fatal/queued/background 等场景分别断言退出码、调用次数和动作只启动一次，不能仅凭名字判为无效。

## 上下文长度的事实

随仓库提供的 Windows 与陪玩描述符为 300000，上限示例为 1047576；测试中的 32768 上下文、64 输出是固定响应夹具。它们不能证明真实比赛可用，也不能直接当成部署默认值。启动器在缺少模型描述符时已有明确报错。

本轮校验的是预算的一致性，没有虚构所有模型都适用的最小窗口，也没有验证上游服务真的支持描述符声明的容量。真实模型带完整提示、工具与长会话的验收仍独立于这些配置测试。

## 重复实现程度

这是维护风险分级，不是重复代码检测器算出的比例。

| 区域 | 判断 | 证据与取舍 |
| --- | --- | --- |
| 桥接 SDK、同步读取与插件补丁 | 高 | `bot-sdk` 约 2500 行；`index.mjs` 维护实体/窗口/事件状态，`local-reads.mjs` 明确跟随 Mineflayer 实现，`plugins.mjs` 读取并改写 Pathfinder 源码。这些适配有旧桥接模式需求，但升级负担高；原生运行时应优先使用真实 bot，避免继续扩张仿真层 |
| 基础协议、数学工具 | 中，且容易清理 | 之前三份 SSE 解析、两份 wire codec 已合并；本轮删除自写向量运算，复用已安装的 vec3。小型 SSE 分帧本身不等于需要引入新框架 |
| 原生模块生命周期 | 高风险，主要不是代码重复 | 全局计时器/console/process.env 包装与代理监听清理形成自有运行框架；取消仍依赖模块配合，链式监听有记录边界。只增加“正常结束”测试不能证明可靠取消 |
| 任务、收件箱、平台消息 | 有必要的领域逻辑 | 续等任务、紧急消息解除等待、按请求边界送达和送达回执是本项目契约。用普通 shell/队列库替换并不会自然保留这些行为 |
| 观察/可达性 | 不能按文件大小判重 | 已复用 Pathfinder、prismarine-world 和 world-memory；空间摘要、可见性及送达后更新基线属于应用逻辑，需要以输出质量和计算成本决定取舍 |

后续事项只维护在 [ROADMAP](../ROADMAP.md#代码整理简化审查中暂缓的项)。

## 验证方式

把新测试临时放回旧实现运行，7 个非法预算判据、1 个向量行为判据、1 个 RPC 错误可见性判据共 9 项全部失败；恢复修复后 9 项全部通过。这比仅观察修改后测试为绿更能证明测试抓住了已知缺陷，但不是穷尽式变异测试。

重点组 31/31 通过；全量 619 项为 552 通过、64 失败、3 跳过。语法、Prettier 与 diff 检查通过。环境中的 Unix socket、chown 等限制仍影响既有集成测试；不能宣称完整端到端验收通过。

隔离工作树重跑基线：609 项、542 通过、64 失败、3 跳过；修改后的 64 个失败名称与基线完全一致，没有新增失败。
